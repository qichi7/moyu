# 越玩越菜（getting-worse）

> **副标题：生存退化** —— 你控制一个不断退化的牛马，在被老板抓住之前，尽量晚一点菜下去。

一个在浏览器中运行的**生存退化小游戏**：牛马放假后开始不可逆退化（牛马 → 猴子 → 草履虫 → 阿巴阿巴分子），天敌（同步退化的老板）步步紧逼，被抓立即退化一级，每 20 秒也会强制退化一级。**存活时间即分数，退化不可逆、能力只降不升**——坚持到分子形态，就能在布朗运动中无限遨游。全程零依赖、零资源文件，单 HTML 文件双击即玩。

- 当前版本：v0.1.0（`BUILD_ID`，右下角徽章可见）
- 技术栈：原生 JavaScript + Canvas 2D + Web Audio API，无任何框架与外部资源（全部像素画由代码程序化烘焙）

> **核心主旨：越玩越菜。** 玩家的能力随时间单调下降，永不回升；唯一的不确定项是被抓时机（加速退化）。分子形态是终点而非奖励——无敌、不可控、分数冻结，只能自己点「假期结束，回去上班」。

## 世界观：PC宇宙

PC宇宙，即 PC 世界观。这个宇宙里的牛马们没日没夜高强度工作，直到有一天开始，他们经历了一次放假——然后所有人就开始退化：

- **大部分人退化了 10,000 倍**，变成了猴子；
- 有少部分人因为放假时间过长，**退化了 100,000,000 倍**，变成了草履虫；
- 草履虫在此基础上**再退化 10,000 倍**，就变成了**分子**。

PC宇宙的分子组成与现实世界不同。例如有一种**阿巴阿巴分子**，由 2 个阿原子和 2 个巴原子组成，会进行布朗运动，震动的时候发出「阿巴阿巴」的声音。

### 分子命名法

| 层级 | 规则 | 示例 |
|------|------|------|
| **学名** | 几X化几Y 计数法 | 二阿化二巴、二嗯化二阿 |
| **化学式** | 元素名 + 数字下标 | 阿2巴2、嗯2阿2 |
| **俗名** | 按分子式中原子排列顺序**连读** | 阿-巴-阿-巴 → **阿巴阿巴**；嗯-嗯-阿-阿 → **嗯嗯阿阿** |

- **分子式必须按读音节拍排列**（阿巴阿巴分子按 阿-巴-阿-巴 排列，而非 阿-阿-巴-巴），连读起来才是它的名字；
- 每种分子震动时发出的是**自己的连读名**（游戏内音效按分子式节拍逐音节合成发声）；
- 已收录分子：**阿巴阿巴**（二阿化二巴，标准布朗）、**嗯嗯阿阿**（二嗯化二阿，迟缓布朗）、**哇呀哇呀**（二哇化二呀，高频布朗）——后两种为分子形态下的触媒变异彩蛋。

## 快速开始

> 工程文件（源码/测试/构建脚本）位于 `dev/` 子目录，`index.html` 为构建产物。Agent 接手请先阅读 `AGENT_HANDOFF.md`。

| 操作 | 命令/方式 |
|------|----------|
| 玩 | 双击 `index.html`（file:// 打开，无缓存问题） |
| 构建产物 | `node dev/build.js`（dev/src 拼接 → 根目录 index.html） |
| 全量测试 | 进入 `dev/` 后 `npm test`（= smoke 24 项 + sprite 37 项 + entry 19 项） |
| 单跑一项 | `node dev/test/smoke.js` / `sprite.js` / `entry.js` |

改任何 `dev/src/*.js` 后必须重新 `node dev/build.js`，`index.html` 是构建产物不直接编辑。

```
    ├── package.json    scripts: build / test
    ├── test/
    │   ├── smoke.js    逻辑冒烟：headless 跑退化链（走位流/站桩流/resize/手动结束），24 项断言
    │   ├── sprite.js   渲染冒烟：软件光栅化跑全套 sprite 烘焙与 drawScene，37 项断言
    │   └── entry.js    入口冒烟：stub DOM 跑构建产物完整启动链 + 开始流程 + 文案契约，19 项断言
    └── src/
        ├── config.js   全局配置：形态表 FORMS、退化倍数、分子变异体 MOLECULES、天敌 PREDATORS、模拟参数 SIM、文案
        ├── rng.js      mulberry32 种子随机 + Box-Muller 正态 + hash2 坐标哈希
        ├── events.js   事件总线（逻辑层 emit，表现层订阅；headless 下无订阅者空转）
        ├── sim.js      模拟核心（零 DOM）：玩家移动/冲刺/击退、天敌 AI、退化链、触媒变异、计分
        ├── sprites.js  像素 Sprite 图集：四形态两帧动画/三天敌/三分子/触媒/背景装饰的 16×16 点阵惰性烘焙
        ├── audio.js    Web Audio 程序化音效（振荡器+噪声合成；分子按连读音节发声）
        ├── render.js   场景编排：drawScene 贴 sprite 图集 + 背景装饰撒点 + 分子氛围粒子
        └── main.js     主入口：固定步长主循环、键盘/触屏摇杆输入、开始/结算界面、HUD、toast、最高纪录
```

**架构原则**：逻辑层（config/rng/events/sim）零 DOM 依赖，可在 node 中 headless 运行；表现层（sprites/audio/render/main）通过 `onEvent` 订阅逻辑事件，不反向侵入。

## 核心机制

### 1. 退化链（形态表）

| 形态 | 已退化倍数 | 速度 | 判定半径 | 特性 |
|------|-----------|------|---------|------|
| 🧑‍💻 牛马 | 0 | 150 | 10 | 满速 + 冲刺（空格，2.5s 冷却） |
| 🐒 猴子 | 1 万 | 112 | 13 | 变大变慢，判定框反而更大 |
| 草履虫 | 1 亿 | 68 | 6 | 纤毛滑行（方向正弦摆动），超小判定框是唯一安慰 |
| 阿巴阿巴分子 | 1 万亿 | 布朗 | 5 | **不可控布朗运动 + 无敌，分数冻结**，点「假期结束，回去上班」手动终局 |

- **强制退化**：每 20 秒（`SIM.DEVOLVE_SECONDS`）自动退化一级，HUD 有倒计时；
- **被捕退化**：被天敌抓到立即退化一级（比倒计时快得多——摸鱼被抓是加速退化的捷径）；
- 退化后 2 秒无敌（防连环抓），天敌集体愣神 1.2 秒看你退化；
- **退化不可逆**：没有任何道具/机制能升回上一形态（核心主旨铁律）。

### 2. 天敌（老板同步退化）

| 玩家形态 | 天敌 | 行为 |
|---------|------|------|
| 牛马 | 西装老板（105 速） | 直线追击 + 包抄摆动 |
| 猴子 | 猩猩老板（95 速） | 同上，摆动频率更低 |
| 草履虫 | 水蚤（60 速） | 慢速游走 + 0.28s 猝发冲刺（×2.6 速） |
| 分子 | 无 | 无敌，天敌全部清场 |

- 形态切换时**天敌原地同步退化**（位置保留——老板也在放假中退化），数量不足自动补员；
- 数量随时间增长：`2 + floor(t/15)`，上限 6；速度成长 `×(1 + min(t/240, 0.35))`；
- 生成点在场地四边随机、离玩家至少 140px；
- **被抓击退**：朝「远离捕食者 + 偏向场心」方向弹飞 0.45s——防止墙角被永久钉死（探针实测的平衡修复）。

### 3. 计分与纪录

- **存活时间即分数**，分子形态到达瞬间**分数冻结**（无限遨游不再涨分）；
- 被抓会加速退化 → 更早冻结 → 分数更低，所以「被抓=加速变菜=丢分」自然成立，无需额外罚分；
- 理论满勤 = 3 × 20s = **60 分整**（一次不被抓走完整个计时链）；
- 最高纪录存 localStorage（`getting-worse-best`）。

### 4. 分子形态（无限遨游）

- 移动 = Ornstein-Uhlenbeck 布朗运动（随机加速度 + 阻尼 + 限速 + 弹墙），输入完全无效；
- 无敌、无天敌、分数冻结，唯一出口是手动点「假期结束，回去上班」；
- 每 8 秒生成一枚**触媒**（存在 12 秒），拾取随机变异为另一种分子（阿巴阿巴 ↔ 嗯嗯阿阿 ↔ 哇呀哇呀），三种分子布朗特性不同（迟缓/标准/高频），变异 toast 同时显示俗名+学名；
- 分子会定时「说话」：按自己的连读音节合成发声（阿巴阿巴分子念 阿-巴-阿-巴）。

### 5. 操作

| 平台 | 操作 |
|------|------|
| 键盘 | 方向键 / WASD 移动；空格冲刺（仅牛马）；Enter 开始/重开 |
| 触屏 | 任意位置按下出虚拟摇杆；右下「冲刺」按钮（仅牛马形态显示） |

移动端按 game-maker-checklist 处理：touch-action:none、position:fixed 锁页面、全 document 监听摇杆（按钮排除）、resize 防抖 120ms。

### 6. 视觉与音效

- 全部画面为 **16×16 细像素点阵**，运行时程序化烘焙到离屏 canvas（缓存键=sprite 名+帧），渲染帧只做 `drawImage`，`image-rendering: pixelated` 保锐利；
- 四形态均带两帧走路/摆动动画；分子为四原子按分子式节拍正弦排列、两帧震动；
- 音效全部由振荡器+噪声合成：退化下滑音、被抓重音、冲刺滑音、触媒琶音、分子连读语音——零音频文件。
