# 小世界（tiny-world）

一个在浏览器中运行的**群岛文明模拟沙盒**：小人在无限延伸的世界里自主生活，世界会根据他们的需求自动生成新区域——建造房屋、开垦农田、架桥填海、开辟新岛，聚落逐步演化成城市。全程零依赖、零资源文件，单 HTML 文件双击即玩。玩家是**纯观察者**：一切演化由小人自主完成，无法被干预。

- 当前版本：v0.6.18（`BUILD_ID`，顶栏徽章可见；v0.6.15→18 三增量：**v0.6.16 气候视觉重做（噪声曲线边界+四类要素贴花，整格 tint 移除）** · **v0.6.17 生态平衡（繁衍均衡化/物种上限补全/狩猎保护线）** · **v0.6.18 时代节奏（升级线 [12,36,90]+扩张每 30 人）**；v0.6.6 娱乐建筑草底修复 · v0.6.7 心情乐事体系（七类乐事×5 档强度） · v0.6.8 圈养回栏受阻退避修复 · v0.6.9 顶栏双行改版 · v0.6.10 马与骑乘 · v0.6.11 水上设施水色底（建筑底图地形感知） · v0.6.12 顶栏美化重排（分组+版本徽章） · v0.6.13 机制演示扩充（15 主题×26×13 大沙盘） · v0.6.14 天象与迁徙（流星/兽群候鸟鲸群周期远行） · v0.6.15 气候系统（气候带/洋流/台风，影响全部压低且 config 化））
- 技术栈：原生 JavaScript + Canvas 2D + Web Audio API，无任何框架与外部资源（全部像素画由代码程序化烘焙）

> **核心主旨：零干预观察者模拟。** 玩家无法对世界演化产生任何影响，只能观察——所有建造/开荒/架桥/探索/命名均由小人自主完成；无指令 UI、无存档干预，玩家的全部操作只是看（视角/缩放/信息框/变速/演示），不改变世界的任何演化。

## 快速开始

> 工程文件（源码/测试/构建脚本）位于 `dev/` 子目录，`index.html` 为构建产物。Agent 接手请先阅读 `AGENT_HANDOFF.md`。

| 操作 | 命令/方式 |
|------|----------|
| 玩 | 双击 `index.html`（file:// 打开，无缓存问题） |
| 构建产物 | `node dev/build.js`（dev/src 拼接 → 根目录 index.html） |
| 全量测试 | `node dev/test/smoke.js && node dev/test/entry.js && node dev/test/voyage.js && node dev/test/creature.js && node dev/test/explorer.js && node dev/test/pixel.js && node dev/test/family.js && node dev/test/drink.js && node dev/test/pack.js && node dev/test/mood.js && node dev/test/species.js && node dev/test/park.js`（逻辑 11 + 入口 24 + 航海 25 + 动物 107 + 探索者 6 + 渲染 79 + 亲子 40 + 饮品 28 + 背包 41 + 心情 71 + 物种 26 + 娱乐 30，部分断言带随机轮空语义） |
| 开发热刷新 | 起 http 服务访问时页面自动检测文件变化并刷新；file:// 下手动 `Cmd+R` |

改任何 `dev/src/*.js` 后必须重新 `node dev/build.js`，`index.html` 是构建产物不直接编辑。

- 全部画面为 **16×16 细像素点阵**：`sprites.js` 在运行时把每种 tile（含海拔档 5 × hash 变体 4）、房屋 24 变体（楼层×石砌×粮仓×亮窗）、**分层像素小人**、十种动物、4 种船、河流水域、水井/酒坊/压榨坊/烘焙坊、咖啡田**程序化烘焙**到离屏 canvas，渲染帧只做 `drawImage`

## 核心机制

### 1. 无限地图（chunk 系统）

- 世界按 **32×32 chunk** 组织，坐标以**主岛为原点 (0,0)**、支持负坐标
- chunk 懒生成：渲染视口（外扩 8 格）触发 `ensureChunksFor` → `generateRegion`；生成结果缓存进 `world.chunks`（Map，key `"cx,cy"`）
- **虚空（VOID）**：未生成区域渲染为深渊色。虚空不是死背景——居民探索到时会点亮并生成内容（见「探索发现与岛屿命名」）；**所有人类单位**（含渔船）走到点亮区边缘都会顺手点亮眼前的虚空（被动点亮，节流 2.5 秒）；远景（zoom<0.4）只生成相机中心 ±40 格
- tile 读取 `tileAt(x,y)`：未生成 → VOID（不可走，BFS 安全，不触发生成）

### 2. 群岛与地形生成

`generateRegion(x0,y0,x1,y1)` 两遍生成：第一遍算**海拔场**并落 tile，第二遍按相邻海拔落差生成**悬崖**：

```
bump = d < r      ? 0.45 × (1 - d/r) + 0.1        （岛体）
     : d < r + 9  ? 0.10 × (1 - (d-r)/9)          （岛缘海域过渡）
     : 0                                            （虚空）
elevation = fbm(x,y) × 0.55 + bump
```

海拔阈值：`<0.28 深海 / <0.38 浅海 / <0.42 沙滩 / >0.68 山（3% 为洞穴·富矿）/ 其余草地（湿度>0.58 时 55% 概率森林，另散布浆果丛 1.2%、果树 0.5%）`。

- 悬崖：陆地格相邻海拔落差 > 0.11 → 悬崖（不可通行）；水域紧邻悬崖处渲染**瀑布**水帘
- 河流：每座岛首次显现时**刻蚀一次**——从山地蜿蜒流向海，河中偶有鱼群、沿岸冲积沙滩（沙土采集点）；河流水格登记进 `world.rivers`（惰性 Set），信息框显示「河流 · 水源」（池塘优先），渲染偏青绿，居民可趴在水边直饮
- 地势差：海拔场存入 chunk（`c.elev`），**坐标海拔直接体现为底色明暗梯度**（高地亮、洼地暗，分 5 档预调色板）；远景缩略图同步
- 初始 3~7 岛随机：主岛（r=14）在原点 + 2~6 座无人岛（r=10~15）环布在 28~36 格的圆环上；**每次开局随机种子生成新地图**（测试固定种子 42）

### 3. 探索行为（点亮虚空的执行者）

- 居民（探险家更频繁）走向虚空边缘 → **以脚下接触位置为中心**点亮一块随机大小、边界不规则（3+5 倍频角向噪声 + 椭圆偏心 + 逐格抖动）的连续斑块 → 变为深海，永久不黑回
- 点亮时按发现网格（48×48，16% 命中）可能显现随机小岛；发现岛的**发现只由居民点亮触发**——视口拖动与工程生成不会让岛凭空冒出
- 发现岛注册进 `world.islands` → 名册「未知岛屿」可定位；**第一个登岛的人为它命名**

### 4. 小人 Agent

每个小人出生即获随机中文名（56 单姓 + 20 复姓 × 男女名字池 24+24，姓氏字段化支持复姓继承）；性别由 id 哈希确定性推导（男女各半、出生定死）。状态机决策优先级：

```
1. 睡觉      energy < 18，或天黑且 energy < 92（回家睡，无家就地睡）
2. 进食      hunger < 30（去最近的进食点：主粮仓/新区粮仓/农田，全球最近；咖啡田不算进食点）
2.5 喝水    thirst < 30（城库有饮品去粮仓饮用，否则找最近水井/河湖直饮——先于领任务，防工蜂化渴死）
3. 搬运      身上有产出 → 送回仓库入库（粮入所在城市粮仓，其余入最近聚落库存）
4. 干活      领取任务（职业匹配优先）→ 走到工地 → 施工
5. 私人生活  按喜好：探索 / 钓鱼 / 陪伴牲畜 / 恋家小范围闲逛
```

- 需求：hunger 每秒 -1.1（吃一次回 100，消耗 1 粮）、thirst 每秒 -1.4（喝水见 4.5 节）、energy 醒时 -0.6 基准 / 睡时 +9；三项需求均按状态系数差分（睡觉/走/跑/干活各不同，见数值表）
- **四方向朝向**：移动按本帧实际位移主轴更新 face（|dx|>|dy| 取水平，否则垂直）；转向统一走 `faceOf/faceTurn` **持锁迟滞防抖**——反向掉头立即切、90° 变向需持锁满 0.8 秒（faceHoldT，小人/动物同口径，斜向阶梯步不再抖头），开工面向任务格的 `faceTo` 显式设向绕锁直设；渲染层把 face 映射为正/侧/背视图（face 缺失容错按 "right"）
- 长期挨饿（hunger<10 持续 40 秒）→ **迁居**到最近进食点旁还有名额的房子
- 分房：一房三户；评分 = 离人距离×0.3 + **离食物距离**×1（住得离吃的远会被强烈劝退）
- 个体属性、职业、喜好、年龄与死亡见下文 8/9 节
- 睡觉躺平冒 z、干活摆动+敲击火花、走路弹跳——纯 Canvas 程序化动画

### 4.5 渴值与饮品链（v0.3.0）

- **渴值**：thirst 0~100，每秒 -1.4（按状态系数差分）；<30 触发喝水决策（优先级在领任务之前，需求分支先于工作），<8 持续 40 秒**脱水病倒**——复用生病机制（信息框显示「生病了」），痊愈需水分恢复到 30 以上，60 秒不治则「因脱水病倒，不治身亡」
- **饮用**：到达水源后原地饮用 2 秒结算——城库存有饮品时按「咖啡 > 果汁 > 麦酒 > 清水」取用（有货优先喝高阶），一次解渴 50~75；城库无饮品（或无城可归）找最近**水井/河湖水格**直饮 +40（无副作用）
- **饮品效果**：麦酒——醉酒 40 秒（移速 ×0.65、饥饿衰减 ×0.85「酒能顶饿」、走路随机踉跄摇晃、信息框标「醉醺醺」）；咖啡——咖啡因 120 秒（精力衰减 ×0.55、信息框标「咖啡提神」）；果汁——额外回复 10 精力；清水——无副作用
- **饮品链建设**（规划署自动立项）：水井（era≥1）→ 酒坊/压榨坊（era≥2）→ 烘焙坊（era≥3），均立在各城粮仓周边、**全域唯一**（先建人口最多的城）；打水/榨汁/酿酒/烘咖啡按库存阈值触发（见任务表与规划器）
- **咖啡田**：文明时代（era≥3）咖啡田不足（人口/20）时新垦——**不产粮**，90 秒产 2 咖啡豆供烘焙坊烘咖啡；选址须 5 格内有水（不为咖啡挖塘，水源优先保粮田），且从粮食产能口径中排除：开荒线、出生线、进食点都只数普通粮田

### 4.6 心情与抑郁（v0.5.0）

- **开心值**：mood 0~100（100 = 开心），基准衰减 0.35/秒、按状态差分（干活 ×1.9 最磨人，睡觉不衰减改回复 +1.0/秒）；**做乐事匹配的事转快乐**（+1.0/秒 × 该乐事强度档位，v0.6.7）——向往远方=航海/铺路搭桥/探索远行（搭桥与远行限向往远方喜好，出海则全民皆乐）、喜爱牲畜=捕获/牧场/牧羊/驯兽、垂钓=捕鱼、恋家=守在家里；随遇而安衰减 ×0.8
- **乐事画像（v0.6.7）**：七类乐事——赏花（浆果丛/果树/月光花旁）/ 喝酒（麦酒）/ 探险（航海·搭桥·远行）/ 爬山（山体悬崖边）/ 垂钓 / 牧畜 / 恋家；每人每类由 id 哈希**确定性分 5 档 0.4~1.8**（不消耗随机流——天生「千杯少」与「沾酒眠」并存），**主喜好对应的乐事保底 1.4 档**（随遇而安无保底）；赏花/爬山人人可享（idle/walk 邻近即被动生效），信息框性格行显示「最爱：XX」（最高档乐事）
- **开心来源**：喝麦酒 +30×酒乐事档位（果汁 12/咖啡 8/清水 3，微醺期间再持续回甘）、丰收宴席全体 +25、**驯服狗 +15 / 驯服独角兽 +25 / 驯服马 +20**、**钓到珍稀鱼 +15~25**、游玩设施（见 13 节）
- **找乐子（v0.6.7 扩展）**：mood<35 时按乐事强度**加权随机**挑去处——喝酒（城库有酒/果汁才去，不拿白水糊弄）、赏花（就近花丛果树）、爬山（就近山脚），先选中项落地失败依次回退其余候选，全落空才冷却
- **抑郁**：mood<12 持续 60 秒 → 什么都不想干（放下任务、不领活、不出海、不救援；吃喝睡保留）；mood≥45 持续 20 秒走出；抑郁累计 300 秒 → 郁结成疾病倒，走不出 60 秒 → 「因长期抑郁病倒，不治身亡」；头顶灰雨云标记、动态面板「抑郁」行可定位

### 7. 寻路

### 8. 历法、年龄与死亡

- **历法**：1 昼夜 = 1 个月，12 昼夜 = 1 年；顶栏显示「第 X 年 · 第 Y 月」
- **年龄**：所有生物随时间变老（1 年 = 1 岁）。寿命：人 80 / 牛 15 / 羊 12 / 狗 10（超过封顶）
- **年龄档**：幼年 / 青年 / 中年 / 老年（阈值见 `config.SPECIES_AGE`）
- **人类育龄**：出生选亲**不分性别统一 20≤年龄≤60**（v0.6.4）——未满 20 岁与年满 60 岁的居民不再生育
- **老死**：进入老年后每天判定死亡概率（60 岁日均 1%，每岁 +0.3%）
- **病亡**：饥饿或精力归零持续 30 秒 → 病倒；再持续 60 秒无救治（吃饱+歇息恢复到 40 以上即痊愈）→ 死亡
- 死亡结算：日志宣告（含享年）、住房与任务释放、名册自动移除
- **讣告广播（v0.6.3）**：信息框打开的居民或动物去世即全屏讣告横幅——姓名（动物显示「一只」+物种名）/死因/享年/死亡地点/时刻，8 秒自动收起、点击任意处致哀（动物死因如寿终正寝/搁浅身亡/被困于陌生的地形/成了狼群的晚餐/被狩猎/被钓起）

所有生物有年龄与寿命（`config.SPECIES_AGE`），按栖息地活动（`habitatOk` 判定），可点击查看信息框（物种/年龄档/状态）。各物种受 `SIM.SPECIES_CAP` 上限守卫（生成与繁衍双处），珍稀物种种群小而延续。

**繁衍、老死与救援**：

- **繁衍**：野生种群按**均衡公式**繁衍（v0.6.17 重构，详见 §12.6）——每物种独立出生预算与硬上限（`SPECIES_CAP` 全表，海龟 12 / 鲸 5 折算同一口径）；繁衍受育龄约束（幼年不育、老年停育，见 §12）
- **老死**：寿命耗尽后平均 3 天内自然离世（概率衰减，避免同龄集体消失）
- **搁浅与被困**：填海造陆等施工会改变地形——脚下不再是栖息地的动物**无法移动**（头顶红色 ! 求救标记），被困超过 180 秒死亡（鲸搁浅有专属纪事文案）
- **救援**：居民会认领被困动物（喜爱牲畜者更积极），把它**搬运**到最近的合适栖息地送回（鲸从岸边送回深海）；无法接近时冷却 60 秒重试，救援者死亡则动物掉落原地继续等待

### 12.6 生态平衡（v0.6.17）

- **均衡繁衍（wildBreedTick 重构）**：旧版「全局池随机选亲、每 tick 陆生至多 1 只」结构性追不上死亡率（探针实测 33 游戏年山羊/鹿/兔/野猪/鱼/鲨/熊/蟹灭绝、狐独占 60 上限）——重构为**每物种均衡出生**：期望出生 = `种群 × 120s ÷ 寿命秒 × WILD_BREED_SAFETY(1.25)`（与死亡率同量纲，替换率留 25% 爬坡余量，种群向物种上限缓慢恢复）；floor + 概率进位取整，超上限钳到 `cap − 种群`；选址失败少生不硬造；亲代须育龄内，**野生优先、无野生取驯服**
- **物种上限补全**：`SPECIES_CAP` 补山羊 40 / 鹿 20 / 野猪 16 / 狼 6（旧版无专键 → 无每物种上限，失衡灭绝根因）；鲸 5（`WHALE_CAP`）/ 海龟 12（`TURTLE_CAP`）折算进统一表；`WILD_BREED_CAP` 60→**120** 且降级为**陆生系全局性能护栏**（超护栏当 tick 跳过陆生繁衍，非生态上限）；**圈养繁殖同受全局 SPECIES_CAP 约束**（单栏 PASTURE_CAP 只限一栏，多栏围捕曾把全局种群顶破上限表）
- **驯化不掏空野生种群**：繁衍计数口径 = 非死亡 + **非圈养**（`pasture` 为空），**驯服（tamed）个体计入**——驯化马/独角兽不再令野生繁衍池枯竭；出生仍落野生，种群自然回补
- **狩猎保护线 `ECO_FLOOR = 4`**：目标物种**非圈养活体**（驯服计入）≤ 4 只 → 该物种**不新立** HUNT/CAPTURE——狩猎（HUNT）、牧场捕获、渔场捕苗**三处立项过滤**（在办任务照常完成，只拦新立项）；物种低于保护线时由均衡繁衍自然回补
- **迁徙周期修正（v0.6.14 单位错误更正）**：v0.6.14 曾把 1 游戏月误按 30 sim 秒折算，迁徙周期实际写成 10800~16200 秒（约为设计意图的 30 倍，兽群几乎不迁）——v0.6.17 修正为 `MIGRATION_PERIOD_MIN/MAX = 4×90 ~ 6×90 = **360~540 秒**`（4~6 游戏月，1 游戏月 = `DAY_LEN` 90s）；距离（30~80 格）与触发概率（50%）不变

### 13. 娱乐链与游乐园（v0.5.0）

- **前期设施**：凉亭（era≥1·人口≥6，每城一座）小憩 3 秒 +12 心情；戏台（era≥2·人口≥10）看戏 5 秒 +18；斗兽场（era≥2·人口≥10）观演 6 秒 +20——均立粮仓周边
- **游乐园**（era≥3·人口≥16·**全域唯一**）：规划署选址**陆地 3×3 连片草地或临城 3×3 连片浅水**（水上乐园），立项圈地（水面格登记 waterCells）；完工水面转**浮台 PIER**（可走）+ 门楼落成；园区内逐个补建**摩天轮 → 旋转木马 → 过山车**
- **游玩闭环**：mood<45 必去、45~70 看心情掷骰（粮食紧张<2 天消耗时不游玩——肚子比开心优先）；走到设施旁驻留数秒结算；**游乐园 +35 心情且获得 300 秒「尽兴而归」余韵（期间心情衰减 ×0.35——开心很持久）**；玩过 120 秒冷却
- 冻结放弃：凉亭/戏台/斗兽场 180 秒无法施工退地；游乐园选址 300 秒放弃（水面还原）

### 14. 航海（码头 → 坐船出海开拓地图）

- **船可以穿过桥**（v0.5.0）：桥格视为可航水域，帆船/渔船/救援船穿越桥线不再靠岸或绕行（靠岸点亦排除桥格）

- **挖塘与灌溉**：居民可把草地挖成水塘（EXCAV）；农田 5 格内有水才能生长（缺水停滞），规划署开垦前先查水源、无水先挖塘引水
- **粮食城市内共享**：每座城市有自己的粮仓（产粮/进食/宴席都在城内结算），名册可查各城存粮；人名、原住民名、岛屿与城市名全局唯一，名字库不足时自动扩展新名
- **池塘与水利**：挖出来的水塘显示为「池塘 · 水源」（青绿色），池塘自动贴着天然水域连片成湖、不零散；连通 ≤4 格的小水域直接填平不架桥；**跨海通路是 1 格宽的细长木桥**（链式逐格生长直通对岸，深海也架桥不填沙），桥下透出水面，不再有菱形填海沙块
- **点亮与扩张**：点亮范围更大（探索者单次约 17~33 格），探索者按人口配置、家随边疆迁移（房子跟着世界边界生长），城市与人口稳步向星空推进
- **地形保护**：点亮虚空、发现岛屿永远不会覆盖已建好的房屋、道路与桥梁（曾有的"山吞房屋、海吞路"问题已修复）；远景缩略图与实际地图实时一致
- **码头**（DOCK）：定居时代（era≥1）解锁，规划署在临水草地自动立项；建成即开启航海时代
- **出海**：探险家职业或「向往远方」喜好且探索欲 > 0.4 的居民空闲时自发走向码头 → 消耗联合木材 10 造船 → 扬帆出海（日志「航海家 XX 从码头扬帆出海」）
- **航程**：船速 3 格/秒、轻微偏航自然弯曲（洋流顺逆与台风另乘修正，见 14.6）；**沿途每 2 秒点亮一片海域**（大面积开拓地图）；航程上限 220 格
- **靠岸**：碰触任何陆地即下船——登岛命名、命名即定居化、原住民相遇全链路自动触发；航程尽头自动返航故乡
- 航海中小人需求冻结（船上有补给）；长期停靠的船会被清理，远航需另造新船

### 14.5 渔船（近海捕捞）

- 有码头且海上有鱼群时，**渔民**（垂钓喜好/渔民职业）自发驾小渔船出海：消耗联合木材 4（远航船为 10），渔船小一号、灰色船身
- 渔船自动驶向最近的鱼点**起网捕捞**（每 10 秒 +2 粮入舱，同时消耗该点鱼群资源）；满舱 20 粮或鱼点枯竭（自动换点，无鱼可捕则空舱返航）
- 回港靠岸即卸货入粮池，渔民下船休整 30 秒后可再次出海；同时最多 2 艘渔船
- 渔民也是人类单位：渔船贴近未点亮海域同样会点亮虚空

### 14.6 天象、迁徙与气候（v0.6.14 / v0.6.15 / v0.6.16~17 修正）

世界有了自己的节律：夜空有流星、海上有洋流与台风、兽群按季节远行、定居区边缘分化出雪带与旱带。**全部影响已刻意压低**（不改变任何决策，只做速度/速率上的微调），全部阈值 config 化（`SIM.METEOR_* / MIGRATION_* / CLIMATE / CURRENT_* / TYPHOON_*`），调度集中在 sim.js `weatherTick`（simUpdate 首个 tick）与 world.js `climateAt/currentAt`。

- **流星（v0.6.14）**：夜间偶现、划空 3 秒（`METEOR_DUR`）——上一颗消散后至少 2~4 游戏夜（`METEOR_GAP_MIN/MAX` = 180~360 秒）才进入掷骰窗口，此后夜间逐秒 2% 概率现身；**目睹流星的小人心情 +0.3/秒**（`METEOR_MOOD`，病倒者无暇仰望，睡觉者走睡眠早退天然排除）
- **动物迁徙（v0.6.14）**：鹿/野猪/马/兔陆生兽群 + 鲸群 + 候鸟，按物种各自周期（`MIGRATION_PERIOD` **4~6 游戏月**）到点掷 50% 概率，向随机方向 **30~80 格**（`MIGRATION_DIST_MIN/MAX`）外的同栖息地远行；**迁徙资格 `migEligible` = 物种表内 + 非圈养 + 未驯化**（鱼/龟/海豚/狼不动，驯化认主的马/狗不迁徙）；途中被栖息地挡住 → 沿 ±90° 切向绕行（5~10 格中转点），到达即恢复定居并排下个周期；**迁徙途中照常可狩猎**（野生动物身份不变），搁浅安全网保留
- **气候带（v0.6.15）**：以**已定居区**（房屋包围盒）南北缘划带——北缘一带（含缘内向北延伸段）为**雪带**：农田生长 ×0.85（`SNOW_FARM`，咖啡田同乘）、浆果再生期望 ×0.8（`SNOW_BERRY`）；南缘对称**干旱带**：农田 ×0.8（`DROUGHT_FARM`）、浆果 ×0.7（`DROUGHT_BERRY`）；中部温带无影响。**带随疆土漂移**（houses 变动即失效 + 60 秒兜底刷新缓存）；浆果再生为整份跳变，因子按格气候落成**概率折算**（`rand()<因子`，期望速率同乘）
- **洋流（v0.6.15）**：16×16 海域块一个 hash 确定性八向流场（`currentAt` 纯函数、无状态）；船速**顺流 ×1.15 / 逆流 ×0.9**（`CURRENT_SHIP_FAST/SLOW`，按航向·流向点积分档）——远航出海/返航/救援 + 渔船出海/归航 **shipTick 五处乘点**共用 `shipEnvMul`
- **台风（v0.6.15）**：小概率生成（`TYPHOON_CHANCE` **1/20000 每秒**，主仓 40~90 格外的深海格），0.5 格/秒漂移、60~120 秒（`TYPHOON_LIFE`）后消散；**半径 12 格（`TYPHOON_R`）圈内：船速 ×0.6（`TYPHOON_SHIP`）、渔船歇网（到点不起网）、行人移速 ×0.85（`TYPHOON_MAN`，1 秒节流邻近缓存）**——只改速度不改决策，风雨过后一切如常
- **气候带（v0.6.15，v0.6.16 边界曲线化）**：以**已定居区**（房屋包围盒）南北缘各内缩 `EDGE_INSET` 10 格为**基线**——北缘基线以北为**雪带**：农田生长 ×0.85（`SNOW_FARM`，咖啡田同乘）、浆果再生期望 ×0.8（`SNOW_BERRY`）；南缘基线以南对称**干旱带**：农田 ×0.8（`DROUGHT_FARM`）、浆果 ×0.7（`DROUGHT_BERRY`）；中部温带无影响。**带随疆土漂移**（houses 变动即失效 + 60 秒兜底刷新缓存）；浆果再生为整份跳变，因子按格气候落成**概率折算**（`rand()<因子`，期望速率同乘）。农田/浆果因子仍按 `climateAt` 三态取档（本条机制不变）
- **气候视觉重做（v0.6.16）——无整格变色、无直线分界**：**雪线/旱线改噪声曲线边界**——基线上叠加 fbm 噪声扰动（x/48 尺度 3 倍频，幅度 `WOBBLE` **±20 格**蜿蜒；雪线/旱线异盐 `(137.5,711.3)/(919.1,313.7)` 错相位）→ 随 x 平滑蜿蜒、犬牙交错，画面上没有任何直线痕迹；新增**连续气候强度场 `climateIntensity(x,y)`**（0~1：离边界深入带内的深度，`FADE` **30 格**线性爬坡、温带为 0）。气候表现全部改为**四类要素贴花**（每类 3 个 hash 变体、透明底 sprite）：
  - 北缘海面**浮冰**（水面/深海，概率 = 强度 × `ICE_P` 0.55）、草地**积雪斑**（`SNOW_P` 0.5）、**山树雪帽**（山/树格，同 SNOW_P）、南缘**枯草斑**（草/沙，`DRY_P` 0.5、沙 ×0.5）
  - 撒点 = `hash2(x,y)` **确定性掷骰**（无每帧随机，同格永远同一结果）——深处浓密、交界稀疏犬牙；s<6 远距不撒（防噪点）
  - **浮冰密集海域船速 ×0.85**（`ICE_SHIP`：水面/深海且强度 ≥0.5，`shipEnvMul` 内远航船/渔船共用，与洋流/台风乘点叠加）
  - 飘雪/浮尘粒子的带范围改按强度场逐行采样——**粒子视觉贴住曲线边界**（不再按直线行扫描）
- **表现层**：流星拖尾、台风螺旋云雨丝与径向暗圈、**气候要素贴花（v0.6.16，四类 sticker）**与带内粒子（飘雪/浮尘）、洋流流纹箭羽（zoom≥0.8）——全部 hash/waveT 确定性绘制（暂停冻结）、契约未落地 falsy 容错退化不画

### 平衡公式（实测校准）

```
人口稳态消耗  ≈ 人口 × 0.011 粮/秒        （hunger 1.1/s ÷ 100）
农田产出      ≈ 农田数 × 0.073 粮/秒      （4 粮 ÷ 55s；咖啡田不产粮、不计入）
→ 每田真实承载 6.6 人，开荒线按 6 人/田配冗余
出生链：产粮田余量(田×5 >= 人口+4) 先行 + 存粮 > 40，人口增长被产能锁定，避免饥荒循环
疆土生长：人口每 +30（EXPAND_EVERY，v0.6.18）触发一次开疆（无人口上限）
聚落升级：繁荣度 = 辖区(14) 房×3 + 田×2，12/36/90 三线（v0.6.18 调低）——城镇 ≈8 房+6 田、城市 ≈20 房+15 田
饮品链：酒/汁各按 人口/12、咖啡按 人口/15、存水按 人口×0.4 配给，咖啡田按 人口/20
```

### 已校准的死锁（历史教训，勿回退）

| 死锁 | 根因 | 现行机制 |
|------|------|---------|
| 建房链条堵死 | `tasksAdd` 缺省 need → 任务永不完工占名额 | TASK_DEFAULT_NEED 兜底 + 闸门排除冻结任务 + 超时放弃 |
| 走廊填海卡死 | 1 维直线任务四周全是水 | 5 格宽条带 + 冻结自愈横向扩宽 |
| 人口-农田互相锁死 | 开荒线与出生线区间不衔接 | 开荒 `田×5 < 人口+8` 高于出生线 `田×5 >= 人口+4`（边界含等号） |
| 工蜂化 | 干活者被排除在吃饭/睡觉判定外 | 需求优先级恒高于工作 |
| 协作任务卡死/重复结算 | 多人同领任务，一人完成后其他工人仍引用已死任务（观测 2106 次挂引用 → 0） | `tasksFinish` 清空所有协同工人的引用 + `doWork` 开头 `t.done` 防御网 |
| 出生边界卡死 | `田×5 > 人口+4` 在 25>25 处严格大于卡死，主岛饱和时两头锁死 | 出生线改 `>=`；开荒选址半径扩至 26 |
| 建筑任务假 workTile 卡死 | PASTURE/QUARRY/SANDPIT 等「落成型」任务走磨血路径永远 false 无出口 | doWork 白名单反转：仅 DIG 走 workTile，其余一律进度制 |
| 桥一格都建不成 | BRIDGE 漏配 need + 资源按最近聚落结算错配 | BRIDGE 补 need=3；国家级工程走联合库存 `jointStock/jointConsume` |

## 已知边界与后续方向

- `config.js` 中 `EXPAND_POP_CAP` 已废弃（人口不设上限），可清理
- 深海/虚空不可走但 `fillable: true`，极端情况可被寻路受阻机制立项填海（远海工程实际不可达，任务会被冻结自愈消化）
- 存粮无上限（宴席是最主要的消耗出口），后期数值可能缓慢膨胀
- 动物有老死（寿命耗尽后概率离世）；狼捕食仅对野生羊生效；鲸鱼喷水柱已随像素化回归（相位与缩放解耦）
- 1000× 时帧率受模拟步进限制（每帧最多 1200 步），如需更快可考虑 worker 线程拆分
- 尚未实现：存档、贸易、小地图、雾状探索遮罩（当前探索即永久可见）。天象/天气（流星/台风/气候带/洋流）已于 v0.6.14/15 落地（见 14.6），影响刻意压低且阈值全部 config 化
