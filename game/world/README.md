# 小世界（tiny-world）

一个在浏览器中运行的**群岛文明模拟沙盒**：小人在无限延伸的世界里自主生活，世界会根据他们的需求自动生成新区域——建造房屋、开垦农田、架桥填海、开辟新岛，聚落逐步演化成城市。全程零依赖、零资源文件，单 HTML 文件双击即玩。

- 当前版本：v0.1.0（`BUILD_ID`，顶栏可见；功能已迭代至探索驱动无限世界）
- 技术栈：原生 JavaScript + Canvas 2D + Web Audio API，无任何框架与外部资源

---

## 快速开始

> 工程文件（源码/测试/构建脚本）位于 `dev/` 子目录，`index.html` 为构建产物。Agent 接手请先阅读 `AGENT_HANDOFF.md`。

| 操作 | 命令/方式 |
|------|----------|
| 玩 | 双击 `index.html`（file:// 打开，无缓存问题） |
| 构建产物 | `node dev/build.js`（dev/src 拼接 → 根目录 index.html） |
| 全量测试 | `node dev/test/smoke.js && node dev/test/entry.js`（逻辑冒烟 10 项 + 入口冒烟 7 项） |
| 开发热刷新 | 起 http 服务访问时页面自动检测文件变化并刷新；file:// 下手动 `Cmd+R` |

改任何 `dev/src/*.js` 后必须重新 `node dev/build.js`，`index.html` 是构建产物不直接编辑。

## 核心机制

### 1. 无限地图（chunk 系统）

- 世界按 **32×32 chunk** 组织，坐标以**主岛为原点 (0,0)**、支持负坐标
- chunk 懒生成：渲染视口（外扩 8 格）触发 `ensureChunksFor` → `generateRegion`；生成结果缓存进 `world.chunks`（Map，key `"cx,cy"`）
- **虚空（VOID）**：未生成区域渲染为深渊色。虚空不是死背景——居民探索到时会点亮并生成内容（见「探索发现与岛屿命名」）；远景（zoom<0.4）只生成相机中心 ±40 格
- tile 读取 `tileAt(x,y)`：未生成 → VOID（不可走，BFS 安全，不触发生成）

### 2. 群岛与地形生成

`generateRegion(x0,y0,x1,y1)` 两遍生成：第一遍算**海拔场**并落 tile，第二遍按相邻海拔落差生成**悬崖**：

```
bump = d < r      ? 0.45 × (1 - d/r) + 0.1        （岛体）
     : d < r + 9  ? 0.10 × (1 - (d-r)/9)          （岛缘海域过渡）
     : 0                                            （虚空）
elevation = fbm(x,y) × 0.55 + bump
```

海拔阈值：`<0.28 深海 / <0.38 浅海 / <0.42 沙滩 / >0.68 山（3% 为洞穴·富矿）/ 其余草地（湿度>0.58 时 55% 概率森林，另散布浆果丛 1.2%、果树 0.5%）`。

- 悬崖：陆地格相邻海拔落差 > 0.11 → 悬崖（不可通行）；水域紧邻悬崖处渲染**瀑布**水帘
- 河流：每座岛首次显现时**刻蚀一次**——从山地蜿蜒流向海，河中偶有鱼群、沿岸冲积沙滩（沙土采集点）
- 地势差：海拔场存入 chunk（`c.elev`），渲染时北高南低画山体阴影、南缘低地画亮边
- 初始 6 岛：主岛（r=14）在原点 + 5 座无人岛（r=10~15）环布在 34~44 格的圆环上；每次开局随机种子生成新地图

### 3. 探索行为（点亮虚空的执行者）

- 居民（探险家更频繁）走向虚空边缘 → **以脚下接触位置为中心**点亮一块随机大小、边界不规则（3+5 倍频角向噪声 + 椭圆偏心 + 逐格抖动）的连续斑块 → 变为深海，永久不黑回
- 点亮时按发现网格（48×48，16% 命中）可能显现随机小岛；发现岛的**发现只由居民点亮触发**——视口拖动与工程生成不会让岛凭空冒出
- 发现岛注册进 `world.islands` → 名册「未知岛屿」可定位；**第一个登岛的人为它命名**

### 4. 小人 Agent

每个小人出生即获随机中文名（20 姓 × 单/双名，约 8000 组合）。状态机决策优先级：

```
1. 睡觉      energy < 18，或天黑且 energy < 92（回家睡，无家就地睡）
2. 进食      hunger < 30（去最近的进食点：主粮仓/新区粮仓/农田，全球最近）
3. 搬运      身上有产出 → 送回仓库入库（粮入全局池，其余入最近聚落库存）
4. 干活      领取任务（职业匹配优先）→ 走到工地 → 施工
5. 私人生活  按喜好：探索 / 钓鱼 / 陪伴牲畜 / 恋家小范围闲逛
```

- 需求：hunger 每秒 -1.1（吃一次回 100，消耗 1 粮）、energy 醒时 -0.9 / 睡时 +9
- 长期挨饿（hunger<10 持续 40 秒）→ **迁居**到最近进食点旁还有名额的房子
- 分房：一房三户；评分 = 离人距离×0.3 + **离食物距离**×1（住得离吃的远会被强烈劝退）
- 个体属性、职业、喜好、年龄与死亡见下文 8/9 节
- 睡觉躺平冒 z、干活摆动+敲击火花、走路弹跳——纯 Canvas 程序化动画

### 5. 任务系统与工程

| 任务类型 | 触发 | 工时 | 成果 |
|---------|------|------|------|
| BUILD 建房 | 容量余量≤2、无家者>6 | 10 | 房屋（一房三户） |
| FARM 开荒 | 每田 6 人承载不足 | 9 | 农田 |
| DIG 开山/伐林 | 航线工程 / 寻路受阻 / 资源低于阈值 | 山 16 / 林 4 | 草地（产出木材 4 / 石材 5 搬运回仓） |
| FILL 填海 | 航线工程（深海） | 14 | 沙滩（自产沙土 2） |
| BRIDGE 架桥 | 航线工程 / 寻路受阻（浅海） | 3 | 木桥（可通行），完工耗木材 1 |
| GATHER 采集 | 沙土/粮压力 + 附近浆果丛/沙滩 | 4 | 粮 3 或沙土 2（搬运回仓） |
| FISH 捕鱼 | 粮食压力 + 近海鱼群（海岸站立） | 5 | 粮 4（搬运回仓） |
| HUNT 狩猎 | 粮食压力 + 附近野生牛羊 | 6 | 肉粮（牛 8 / 羊 5，搬运回仓），猎犬助阵效率 ×1.5 |
| PASTURE 牧场 | 城邦时代 | 16 | 牧场 + 自动围栏圈地 |
| CAPTURE 捕获 | 有牧场空位 + 附近野生牲畜 | 5 | 牲畜入栏 |
| QUARRY 采石场 | 城邦时代 + 洞穴旁 | 18 | +3 石材/80 秒 |
| SANDPIT 沙场 | 城邦时代 + 河滩/海岸 | 12 | +2 沙土/80 秒 |
| PLANT 植树 | 木材 < 15 | 6 | 树（木材再生） |
| PLANT_BERRY 培育浆果 | 丛数 < 6+人口/4 且有丛可采种 | 5 | 新浆果丛（果量 1 起步再生） |

- 工地并发：建造类 2 人、工程类 4 人；每秒进度 = 工人数 × WORK_EFFORT(1.3) × 勤劳系数
- **领任务三级排序**：资源不足的工程任务直接跳过（小人转做采集）→ `blockedCount` 降序 → 职业匹配 −5000 → 距离升序（职业匹配不锁死）
- 冻结自愈：任务被"路不通"冻结 3 次后冻结；60 秒自动在周围 2 格补立项（推进前沿横向扩宽）；建造类挣扎 180 秒仍无法施工则放弃退地
- **协作完成结算**：任务完成时清空所有协同工人的引用（防卡死/重复结算）；产出由完成者背包搬运回仓
- 走廊工程：扩张时主城 → 新区生成 **7 格宽条带**的改造任务（浅水架桥、深海填海），两岸相向推进直至接通——1 维直线会被弧形海岸卡死，宽度是关键

### 6. 规划器（需求聚合 → 世界生成）

每 4 sim 秒运行一次，聚合小人状态驱动世界：

```
1. 住房前瞻     capacity(房×3) - 人口 ≤ 2，或无家者 > 6 → 建房
                锚点：无家者重心优先，失败退化为粮仓锚点
                选址失败（本区塞满）→ 直接开辟新区（expand）
2. 粮食压力     农田×5 < 人口+8 → 开荒；锚点：挨饿人群重心（哪里饿田在哪）
3. 饥荒告警     存粮 < 1 天消耗 → 日志 + 警示音（1 天节流）
4. 出生         人口 < 上限 且 存粮 > 100 且 农田×5 > 人口+4 且 房有富余
                （由农田承载余量驱动，饥荒期停止生育；6 成概率生在已升级聚落）
5. 世界扩张     人口 ≥ popCap → 渡海激活最近无人岛 / 向远海造新岛
                新区配套：粮仓直接落成 + 3 建房 + 2 开荒任务 + 聚落注册
6. 冻结自愈     见任务系统
7. 丰收宴席     存粮 > 60 + 人口×5（3 天一次）：扣 40+人口 粮，全城饱食+精力
8. 聚落演化     繁荣度 = 辖区(半径14)内 房×3 + 田×2
                ≥24 村庄 / ≥70 城镇（石砌建筑+城内自动铺路+蓝旗）/ ≥150 城市（红旗）
```

### 7. 寻路

- BFS 四方向，**以起点为中心 160×160 滑动窗口**（stamp 复用 + 代次标记），节点上限 20000
- 目标不可走 → 自动取其相邻可走格；搜索中记录「最近的不可通行格」（blocked）
- 寻路失败且 blocked 是山/水/林 → 60% 概率自动立项改造（协作修路的来源之一）
- 目标/起点出窗 → 不可达（走廊工程分段推进，天然不需要跨窗寻路）

### 8. 历法、年龄与死亡

- **历法**：1 昼夜 = 1 个月，12 昼夜 = 1 年；顶栏显示「第 X 年 · 第 Y 月」
- **年龄**：所有生物随时间变老（1 年 = 1 岁）。寿命：人 80 / 牛 15 / 羊 12 / 狗 10（超过封顶）
- **年龄档**：幼年 / 青年 / 中年 / 老年（阈值见 `config.SPECIES_AGE`）
- **老死**：进入老年后每天判定死亡概率（60 岁日均 1%，每岁 +0.3%）
- **病亡**：饥饿或精力归零持续 30 秒 → 病倒；再持续 60 秒无救治（吃饱+歇息恢复到 40 以上即痊愈）→ 死亡
- 死亡结算：日志宣告（含享年）、住房与任务释放、名册自动移除

### 9. 个体属性、职业与喜好

| 维度 | 说明 |
|------|------|
| 探索欲（0~1） | 驱动自发探索远行；档位：家里蹲 / 安分守己 / 向往外面 / 天生探险家 |
| 勤劳（0.25~1） | 干活效率 ±30%；档位：偷奸耍滑 / 随大流 / 勤快 / 工作狂 |
| 职业 | 探索欲>0.75 → 探险家、勤劳>0.8 → 工匠，其余随机（农夫/伐木工/采石工/猎人/渔民）；领取匹配职业的任务大幅优先（不锁死） |
| 喜好 | 向往远方 / 恋家（活动半径缩小）/ 喜爱牲畜（陪伴牧场加速产粮）/ 垂钓爱好者（空闲自发钓鱼 +2 粮）/ 随遇而安 |

### 10. 探索发现与岛屿命名

- 居民（尤其探险家）走向虚空边缘 → 以脚下接触位置为中心点亮一块**随机大小的不规则斑块**（变为深海，永久不黑回）
- 点亮时按发现网格（48×48，16% 命中）可能显现随机小岛；60% 概率存在**原住民部落**（2~4 人加入世界，居民为其筹建第一座居所）
- **第一个登上未知岛屿的人为它取名**，名册「未知岛屿」列表同步显示
- 显现的岛屿注册为扩张候选；河岛可能自带**河流**（含鱼群与冲积沙滩）

### 11. 地形与资源渠道

- **地势与地貌**：海拔场驱动悬崖生成（山脚/高地边缘）、洞穴（山中 3%，富矿）、河流（每岛刻蚀一次，蜿蜒入海，河岸冲积沙滩、有鱼群）、瀑布（水域紧邻悬崖处的流动水帘）、地势阴影渲染、草地点缀小花
- **不可再生资源的渠道**（受沙石限制时的出路）：

| 资源 | 主渠道 | 替代渠道（城邦时代解锁） |
|------|--------|------------------------|
| 木材 | 伐树 +4/棵 | 植树任务（种树再生，低于 15 自动立项） |
| 石材 | 采石 +5/座 | **采石场**（洞穴旁建造，+3 石/80 秒） |
| 沙土 | 采沙 +2/次、填海自产 +2 | **沙场**（河滩/海岸建造，+2 沙/80 秒） |

- **搬运语义**：采集/狩猎产出由小人**背包搬运回仓库才入库**（信息框显示「背着：木材×4（回仓入库中）」），死亡时背包散失——名册显示的数字永远是仓库里的

### 12. 围栏与畜牧

- 牧场建成时自动在四周立起**围栏**（不可通行），圈养的牲畜只能在栏内游荡
- 圈养牲畜定期产粮（+2/80 秒）、缓慢繁殖（10%/120 秒，单栏上限 6 头）；喜爱牲畜的居民靠近可加速产出

### 13. 音效（程序化合成）

| 事件 | 音色 |
|------|------|
| 按钮/变速 | 短促 tick |
| 竣工/开荒 | 三角波和弦上行 / 轻快双音 |
| 出生 | 清脆上扬 |
| 开辟新区 | 低音号角 + 闷雷噪声 |
| 宴席 | 四音琶音 |
| 饥荒 | 锯齿波下沉（30s 节流） |
| 黄昏/黎明 | 柔和氛围音 |
| 聚落升级 | 庄严和弦 |
| 发现新大陆 | 神秘上扬琶音 |

所有音效由振荡器 + 音量包络 + 带通噪声合成，无音频文件；全局节流表防止刷屏；AudioContext 在首次用户手势后初始化。

| 资源消耗 | 架桥 1 木/格、铺路 1 石/格、造陆 2 沙/格 | 库存不足工程挂起，自动立项补充采集 |
| 岛屿上限 | 40 座 | 达到后扩张只放宽人口上限 |

### 平衡公式（实测校准）

```
人口稳态消耗  ≈ 人口 × 0.011 粮/秒        （hunger 1.1/s ÷ 100）
农田产出      ≈ 农田数 × 0.073 粮/秒      （4 粮 ÷ 55s）
→ 每田真实承载 6.6 人，开荒线按 5 人/田配 25% 冗余
出生链：农田余量(田×5 > 人口+4) 先行，人口增长被产能锁定，避免饥荒循环
```

### 已校准的死锁（历史教训，勿回退）

| 死锁 | 根因 | 现行机制 |
|------|------|---------|
| 建房链条堵死 | `tasksAdd` 缺省 need → 任务永不完工占名额 | TASK_DEFAULT_NEED 兜底 + 闸门排除冻结任务 + 超时放弃 |
| 走廊填海卡死 | 1 维直线任务四周全是水 | 7 格宽条带 + 冻结自愈横向扩宽 |
| 人口-农田互相锁死 | 开荒线与出生线区间不衔接 | 开荒 `田×5 < 人口+8` 高于出生线 `田×5 >= 人口+4`（边界含等号） |
| 工蜂化 | 干活者被排除在吃饭/睡觉判定外 | 需求优先级恒高于工作 |
| 协作任务卡死/重复结算 | 多人同领任务，一人完成后其他工人仍引用已死任务：改造类对废工地无限发呆、进度类重复结算（双倍产粮/双份房屋） | `tasksFinish` 清空所有协同工人的引用 + `doWork` 开头 `t.done` 防御网（观测 2106 次挂引用 → 0） |
| 出生边界卡死 | `田×5 > 人口+4` 在 25>25 处严格大于卡死，主岛饱和时两头锁死 | 出生线改 `>=`；开荒选址半径扩至 26 |

## 已知边界与后续方向

- `config.js` 中 `WORLD_W / WORLD_H / INIT_REGION` 为无限地图重构后的死配置，可清理
- 深海/虚空不可走但 `fillable: true`，极端情况可被寻路受阻机制立项填海（远海工程实际不可达，任务会被冻结自愈消化）
- 存粮无上限（宴席是最主要的消耗出口），后期数值可能缓慢膨胀
- 尚未实现：存档、职业分工、死亡、贸易、小地图、雾状探索遮罩（当前探索即永久可见）
- 长期挂机 100× 时渲染为瓶颈（每帧最多 240 sim 步），如需更快可考虑 worker 线程拆分模拟
