# 小世界（tiny-world）

一个在浏览器中运行的**群岛文明模拟沙盒**：小人在无限延伸的世界里自主生活，世界会根据他们的需求自动生成新区域——建造房屋、开垦农田、架桥填海、开辟新岛，聚落逐步演化成城市。全程零依赖、零资源文件，单 HTML 文件双击即玩。

- 当前版本：v0.6.0（`BUILD_ID`，顶栏可见；v0.5.0 心情+物种+娱乐、v0.5.1~v0.5.9 九连小版本、**v0.6.0 看护补齐 + 机制演示 + 玩法教程**）
- 技术栈：原生 JavaScript + Canvas 2D + Web Audio API，无任何框架与外部资源（全部像素画由代码程序化烘焙）

---

## 快速开始

> 工程文件（源码/测试/构建脚本）位于 `dev/` 子目录，`index.html` 为构建产物。Agent 接手请先阅读 `AGENT_HANDOFF.md`。

| 操作 | 命令/方式 |
|------|----------|
| 玩 | 双击 `index.html`（file:// 打开，无缓存问题） |
| 构建产物 | `node dev/build.js`（dev/src 拼接 → 根目录 index.html） |
| 全量测试 | `node dev/test/smoke.js && node dev/test/entry.js && node dev/test/voyage.js && node dev/test/creature.js && node dev/test/explorer.js && node dev/test/pixel.js && node dev/test/family.js && node dev/test/drink.js && node dev/test/pack.js && node dev/test/mood.js && node dev/test/species.js && node dev/test/park.js`（逻辑 11 + 入口 7 + 航海 21 + 动物 27 + 探索者 6 + 渲染 52 + 亲子 36 + 饮品 28 + 背包 41 + 心情 26 + 物种 21 + 娱乐 26，部分断言带随机轮空语义） |
| 开发热刷新 | 起 http 服务访问时页面自动检测文件变化并刷新；file:// 下手动 `Cmd+R` |

改任何 `dev/src/*.js` 后必须重新 `node dev/build.js`，`index.html` 是构建产物不直接编辑。

### 0. 像素画风（v0.2.0）

- 全部画面为 **16×16 细像素点阵**：`sprites.js` 在运行时把每种 tile（含海拔档 5 × hash 变体 4）、房屋 24 变体（楼层×石砌×粮仓×亮窗）、**分层像素小人**、十种动物、4 种船、河流水域、水井/酒坊/压榨坊/烘焙坊、咖啡田**程序化烘焙**到离屏 canvas，渲染帧只做 `drawImage`
- **分层像素小人**：外观由 `agentLook(id)` 对 id 哈希确定性取档（肤色 3 × 日常衣 10 × 裤色 6 × 发色 5 × 发型 4）；发型分性别池——女（长发/发髻+头花/短发/草帽）、男（短发/光头/草帽/斗笠），原住民头顶白羽
- **小人按层叠加**：head（大头 6×6+发型）/ body（25 姿态 × 三视图）/ pants（双腿+鞋 × 双视图）+ 资源背包同锚叠画——body 25 姿态覆盖站/走两帧/跑两帧（前倾+大摆臂）/躺睡/抡锤/伐木斧/锄/锹/进食/持竿/划船坐姿/饮用举杯两帧/酿造搅拌两帧/醉酒跌倒；衣色随状态（干活橙、睡觉蓝、其余日常衣）
- **四方向朝向**：小人/动物的 face（up/down/left/right）映射到视图——down=正面 / up=背面 / 左右=侧面（left 水平镜像）；head 层分正面（双眼）/侧面（单眼侧脸）/背面（后脑），body/pants 正背面归一为对称画法（带中缝细节）；十种动物均有正/背视点阵，鱼群按绕游切线朝向
- **性别剪裁**：女性连衣裙锥形下摆（走/跑裙摆左右摆动、坐姿裙覆盖、躺睡平铺、裙下露腿用肤色）；男性直身摆
- **动作画面**：钓鱼持竿画竿线+随波浮标（红白 2px）；船内水手坐姿划桨（双桨两帧摆动、桨尖出舷）；背包按携带资源显示 9 种（麻袋/柴捆/灰石/沙袋/木水桶/果篮/酒坛/咖啡袋/豆袋）；走路/跑步带起伏 bob，醉酒水平踉跄摇晃+偶发跌倒帧
- **河流与新工坊**：河流水格偏青绿（区别海蓝）4 帧波纹；水井（辘轳+吊桶）/酒坊（红幌+酒坛）/压榨坊（敞棚榨槽）/烘焙坊（烟囱炉火）为 16×24 画布向上探出的建筑 sprite；咖啡田为深土垄+咖啡矮株+红果
- 缩放语义：zoom≥1 关闭平滑（锐利方块感）、0.4~1 开启平滑（缩小防闪烁）、<0.4 走 1 格=1 像素的 chunk 缩略图（同为像素风）
- 细节层：水面 4 帧波纹动画（暂停即冻结）、海岸浪花描边、草地→沙滩抖动过渡、夜间亮窗、瀑布水帘、草地点缀小花

- 动画修正：鱼群绕游/鸟扑翼/鲸喷水改用模拟时钟（旧版误用缩放值当时间）

## 核心机制

### 1. 无限地图（chunk 系统）

- 世界按 **32×32 chunk** 组织，坐标以**主岛为原点 (0,0)**、支持负坐标
- chunk 懒生成：渲染视口（外扩 8 格）触发 `ensureChunksFor` → `generateRegion`；生成结果缓存进 `world.chunks`（Map，key `"cx,cy"`）
- **虚空（VOID）**：未生成区域渲染为深渊色。虚空不是死背景——居民探索到时会点亮并生成内容（见「探索发现与岛屿命名」）；**所有人类单位**（含渔船）走到点亮区边缘都会顺手点亮眼前的虚空（被动点亮，节流 2.5 秒）；远景（zoom<0.4）只生成相机中心 ±40 格
- tile 读取 `tileAt(x,y)`：未生成 → VOID（不可走，BFS 安全，不触发生成）

### 2. 群岛与地形生成

`generateRegion(x0,y0,x1,y1)` 两遍生成：第一遍算**海拔场**并落 tile，第二遍按相邻海拔落差生成**悬崖**：

```
bump = d < r      ? 0.45 × (1 - d/r) + 0.1        （岛体）
     : d < r + 9  ? 0.10 × (1 - (d-r)/9)          （岛缘海域过渡）
     : 0                                            （虚空）
elevation = fbm(x,y) × 0.55 + bump
```

海拔阈值：`<0.28 深海 / <0.38 浅海 / <0.42 沙滩 / >0.68 山（3% 为洞穴·富矿）/ 其余草地（湿度>0.58 时 55% 概率森林，另散布浆果丛 1.2%、果树 0.5%）`。

- 悬崖：陆地格相邻海拔落差 > 0.11 → 悬崖（不可通行）；水域紧邻悬崖处渲染**瀑布**水帘
- 河流：每座岛首次显现时**刻蚀一次**——从山地蜿蜒流向海，河中偶有鱼群、沿岸冲积沙滩（沙土采集点）；河流水格登记进 `world.rivers`（惰性 Set），信息框显示「河流 · 水源」（池塘优先），渲染偏青绿，居民可趴在水边直饮
- 地势差：海拔场存入 chunk（`c.elev`），**坐标海拔直接体现为底色明暗梯度**（高地亮、洼地暗，分 5 档预调色板）；远景缩略图同步
- 初始 3~7 岛随机：主岛（r=14）在原点 + 2~6 座无人岛（r=10~15）环布在 28~36 格的圆环上；**每次开局随机种子生成新地图**（测试固定种子 42）

### 3. 探索行为（点亮虚空的执行者）

- 居民（探险家更频繁）走向虚空边缘 → **以脚下接触位置为中心**点亮一块随机大小、边界不规则（3+5 倍频角向噪声 + 椭圆偏心 + 逐格抖动）的连续斑块 → 变为深海，永久不黑回
- 点亮时按发现网格（48×48，16% 命中）可能显现随机小岛；发现岛的**发现只由居民点亮触发**——视口拖动与工程生成不会让岛凭空冒出
- 发现岛注册进 `world.islands` → 名册「未知岛屿」可定位；**第一个登岛的人为它命名**

### 4. 小人 Agent

每个小人出生即获随机中文名（56 单姓 + 20 复姓 × 男女名字池 24+24，姓氏字段化支持复姓继承）；性别由 id 哈希确定性推导（男女各半、出生定死）。状态机决策优先级：

```
1. 睡觉      energy < 18，或天黑且 energy < 92（回家睡，无家就地睡）
2. 进食      hunger < 30（去最近的进食点：主粮仓/新区粮仓/农田，全球最近；咖啡田不算进食点）
2.5 喝水    thirst < 30（城库有饮品去粮仓饮用，否则找最近水井/河湖直饮——先于领任务，防工蜂化渴死）
3. 搬运      身上有产出 → 送回仓库入库（粮入所在城市粮仓，其余入最近聚落库存）
4. 干活      领取任务（职业匹配优先）→ 走到工地 → 施工
5. 私人生活  按喜好：探索 / 钓鱼 / 陪伴牲畜 / 恋家小范围闲逛
```

- 需求：hunger 每秒 -1.1（吃一次回 100，消耗 1 粮）、thirst 每秒 -1.4（喝水见 4.5 节）、energy 醒时 -0.6 基准 / 睡时 +9；三项需求均按状态系数差分（睡觉/走/跑/干活各不同，见数值表）
- **四方向朝向**：移动按本帧实际位移主轴更新 face（|dx|>|dy| 取水平，否则垂直）；转向统一走 `faceOf/faceTurn` **持锁迟滞防抖**——反向掉头立即切、90° 变向需持锁满 0.8 秒（faceHoldT，小人/动物同口径，斜向阶梯步不再抖头），开工面向任务格的 `faceTo` 显式设向绕锁直设；渲染层把 face 映射为正/侧/背视图（face 缺失容错按 "right"）
- 长期挨饿（hunger<10 持续 40 秒）→ **迁居**到最近进食点旁还有名额的房子
- 分房：一房三户；评分 = 离人距离×0.3 + **离食物距离**×1（住得离吃的远会被强烈劝退）
- 个体属性、职业、喜好、年龄与死亡见下文 8/9 节
- 睡觉躺平冒 z、干活摆动+敲击火花、走路弹跳——纯 Canvas 程序化动画

### 4.5 渴值与饮品链（v0.3.0）

- **渴值**：thirst 0~100，每秒 -1.4（按状态系数差分）；<30 触发喝水决策（优先级在领任务之前，需求分支先于工作），<8 持续 40 秒**脱水病倒**——复用生病机制（信息框显示「生病了」），痊愈需水分恢复到 30 以上，60 秒不治则「因脱水病倒，不治身亡」
- **饮用**：到达水源后原地饮用 2 秒结算——城库存有饮品时按「咖啡 > 果汁 > 麦酒 > 清水」取用（有货优先喝高阶），一次解渴 50~75；城库无饮品（或无城可归）找最近**水井/河湖水格**直饮 +40（无副作用）
- **饮品效果**：麦酒——醉酒 40 秒（移速 ×0.65、饥饿衰减 ×0.85「酒能顶饿」、走路随机踉跄摇晃、信息框标「醉醺醺」）；咖啡——咖啡因 120 秒（精力衰减 ×0.55、信息框标「咖啡提神」）；果汁——额外回复 10 精力；清水——无副作用
- **饮品链建设**（规划署自动立项）：水井（era≥1）→ 酒坊/压榨坊（era≥2）→ 烘焙坊（era≥3），均立在各城粮仓周边、**全域唯一**（先建人口最多的城）；打水/榨汁/酿酒/烘咖啡按库存阈值触发（见任务表与规划器）
- **咖啡田**：文明时代（era≥3）咖啡田不足（人口/20）时新垦——**不产粮**，90 秒产 2 咖啡豆供烘焙坊烘咖啡；选址须 5 格内有水（不为咖啡挖塘，水源优先保粮田），且从粮食产能口径中排除：开荒线、出生线、进食点都只数普通粮田

### 4.6 心情与抑郁（v0.5.0）

- **开心值**：mood 0~100（100 = 开心），基准衰减 0.35/秒、按状态差分（干活 ×1.9 最磨人，睡觉不衰减改回复 +1.0/秒）；**做喜好匹配的事转快乐**（+1.0/秒覆盖衰减）——向往远方=航海/铺路搭桥/探索远行、喜爱牲畜=捕获/牧场/牧羊/驯兽、垂钓=捕鱼、恋家=守在家里；随遇而安衰减 ×0.8
- **开心来源**：喝麦酒 +30（果汁 12/咖啡 8/清水 3，微醺期间再持续回甘）、丰收宴席全体 +25、**驯服狗 +15 / 驯服独角兽 +25**、**钓到珍稀鱼 +15~25**、游玩设施（见 13 节）
- **找乐子**：mood<35 且城库有酒/果汁 → 先去喝一杯（不为解渴为开心，拿白水糊弄是不行的）
- **抑郁**：mood<12 持续 60 秒 → 什么都不想干（放下任务、不领活、不出海、不救援；吃喝睡保留）；mood≥45 持续 20 秒走出；抑郁累计 300 秒 → 郁结成疾病倒，走不出 60 秒 → 「因长期抑郁病倒，不治身亡」；头顶灰雨云标记、动态面板「抑郁」行可定位

- **领任务三级排序**：资源不足的工程任务直接跳过（小人转做采集）→ `blockedCount` 降序 → 职业匹配 −5000 → 距离升序 + **任务老化插队**（立项越久越优先，远任务不饿死；职业匹配不锁死）
- 冻结自愈：任务被"路不通"冻结 3 次后冻结；60 秒自动在周围 2 格补立项（推进前沿横向扩宽）；建造类挣扎 180 秒仍无法施工则放弃退地
- **协作完成结算**：任务完成时清空所有协同工人的引用（防卡死/重复结算）；产出由完成者背包搬运回仓
- 走廊工程：扩张时主城 → 新区生成 **5 格宽条带**的改造任务（浅水架桥、深海填海），两岸相向推进直至接通——1 维直线会被弧形海岸卡死，宽度是关键

### 7. 寻路

### 8. 历法、年龄与死亡

- **历法**：1 昼夜 = 1 个月，12 昼夜 = 1 年；顶栏显示「第 X 年 · 第 Y 月」
- **年龄**：所有生物随时间变老（1 年 = 1 岁）。寿命：人 80 / 牛 15 / 羊 12 / 狗 10（超过封顶）
- **年龄档**：幼年 / 青年 / 中年 / 老年（阈值见 `config.SPECIES_AGE`）
- **老死**：进入老年后每天判定死亡概率（60 岁日均 1%，每岁 +0.3%）
- **病亡**：饥饿或精力归零持续 30 秒 → 病倒；再持续 60 秒无救治（吃饱+歇息恢复到 40 以上即痊愈）→ 死亡
- 死亡结算：日志宣告（含享年）、住房与任务释放、名册自动移除

- **池塘与水利**：挖出来的水塘显示为「池塘 · 水源」（青绿色），池塘自动贴着天然水域连片成湖、不零散；连通 ≤4 格的小水域直接填平不架桥；**跨海通路是 1 格宽的细长木桥**（链式逐格生长直通对岸，深海也架桥不填沙），桥下透出水面，不再有菱形填海沙块
- **点亮与扩张**：点亮范围更大（探索者单次约 17~33 格），探索者按人口配置、家随边疆迁移（房子跟着世界边界生长），城市与人口稳步向星空推进
- **地形保护**：点亮虚空、发现岛屿永远不会覆盖已建好的房屋、道路与桥梁（曾有的"山吞房屋、海吞路"问题已修复）；远景缩略图与实际地图实时一致
- **码头**（DOCK）：定居时代（era≥1）解锁，规划署在临水草地自动立项；建成即开启航海时代
- **出海**：探险家职业或「向往远方」喜好且探索欲 > 0.4 的居民空闲时自发走向码头 → 消耗联合木材 10 造船 → 扬帆出海（日志「航海家 XX 从码头扬帆出海」）
- **航程**：船速 3 格/秒、轻微偏航自然弯曲；**沿途每 2 秒点亮一片海域**（大面积开拓地图）；航程上限 220 格
- **靠岸**：碰触任何陆地即下船——登岛命名、命名即定居化、原住民相遇全链路自动触发；航程尽头自动返航故乡
- 航海中小人需求冻结（船上有补给）；长期停靠的船会被清理，远航需另造新船

### 14.5 渔船（近海捕捞）

- 有码头且海上有鱼群时，**渔民**（垂钓喜好/渔民职业）自发驾小渔船出海：消耗联合木材 4（远航船为 10），渔船小一号、灰色船身
- 渔船自动驶向最近的鱼点**起网捕捞**（每 10 秒 +2 粮入舱，同时消耗该点鱼群资源）；满舱 20 粮或鱼点枯竭（自动换点，无鱼可捕则空舱返航）
- 回港靠岸即卸货入粮池，渔民下船休整 30 秒后可再次出海；同时最多 2 艘渔船
- 渔民也是人类单位：渔船贴近未点亮海域同样会点亮虚空

### 平衡公式（实测校准）

```
人口稳态消耗  ≈ 人口 × 0.011 粮/秒        （hunger 1.1/s ÷ 100）
农田产出      ≈ 农田数 × 0.073 粮/秒      （4 粮 ÷ 55s；咖啡田不产粮、不计入）
→ 每田真实承载 6.6 人，开荒线按 6 人/田配冗余
出生链：产粮田余量(田×5 >= 人口+4) 先行 + 存粮 > 40，人口增长被产能锁定，避免饥荒循环
疆土生长：人口每 +25 触发一次开疆（无人口上限）
饮品链：酒/汁各按 人口/12、咖啡按 人口/15、存水按 人口×0.4 配给，咖啡田按 人口/20
```

### 已校准的死锁（历史教训，勿回退）

| 死锁 | 根因 | 现行机制 |
|------|------|---------|
| 建房链条堵死 | `tasksAdd` 缺省 need → 任务永不完工占名额 | TASK_DEFAULT_NEED 兜底 + 闸门排除冻结任务 + 超时放弃 |
| 走廊填海卡死 | 1 维直线任务四周全是水 | 5 格宽条带 + 冻结自愈横向扩宽 |
| 人口-农田互相锁死 | 开荒线与出生线区间不衔接 | 开荒 `田×5 < 人口+8` 高于出生线 `田×5 >= 人口+4`（边界含等号） |
| 工蜂化 | 干活者被排除在吃饭/睡觉判定外 | 需求优先级恒高于工作 |
| 协作任务卡死/重复结算 | 多人同领任务，一人完成后其他工人仍引用已死任务（观测 2106 次挂引用 → 0） | `tasksFinish` 清空所有协同工人的引用 + `doWork` 开头 `t.done` 防御网 |
| 出生边界卡死 | `田×5 > 人口+4` 在 25>25 处严格大于卡死，主岛饱和时两头锁死 | 出生线改 `>=`；开荒选址半径扩至 26 |
| 建筑任务假 workTile 卡死 | PASTURE/QUARRY/SANDPIT 等「落成型」任务走磨血路径永远 false 无出口 | doWork 白名单反转：仅 DIG 走 workTile，其余一律进度制 |
| 桥一格都建不成 | BRIDGE 漏配 need + 资源按最近聚落结算错配 | BRIDGE 补 need=3；国家级工程走联合库存 `jointStock/jointConsume` |

## 已知边界与后续方向

- `config.js` 中 `EXPAND_POP_CAP` 已废弃（人口不设上限），可清理
- 深海/虚空不可走但 `fillable: true`，极端情况可被寻路受阻机制立项填海（远海工程实际不可达，任务会被冻结自愈消化）
- 存粮无上限（宴席是最主要的消耗出口），后期数值可能缓慢膨胀
- 动物有老死（寿命耗尽后概率离世）；狼捕食仅对野生羊生效；鲸鱼喷水柱已随像素化回归（相位与缩放解耦）
- 远景缩略图缓存不随施工失效（1.4px/格 下不可感知）；1000× 时帧率受模拟步进限制（每帧最多 1200 步），如需更快可考虑 worker 线程拆分
- 尚未实现：存档、昼夜视觉封顶 10× 以外的天气系统、贸易、小地图、雾状探索遮罩（当前探索即永久可见）
